RUSTCOIN — PEMBARUAN RENCANA DISTRIBUSI TOKENOMICS
====================================================
Paket ini menambahkan visual rencana distribusi RST pada website.

UNGGAH FILE KE ROOT REPOSITORI GITHUB:
- index.html
- RUSTCOIN_LOGO.png
- favicon.png
- favicon.ico

Langkah:
1. Ekstrak ZIP.
2. Buka repositori https://github.com/rustambp76-del/RUSTCOIN
3. Pilih Add file > Upload files.
4. Unggah file-file di atas ke folder utama repositori.
5. Klik Commit changes.
6. Setelah GitHub Pages memperbarui situs, buka website dan tekan Ctrl+F5.

Rencana alokasi yang disetujui:
- Komunitas & ekosistem: 30% = 150.000.000 RST
- Pengembangan proyek: 25% = 125.000.000 RST
- Cadangan proyek: 20% = 100.000.000 RST
- Insentif & penghargaan: 15% = 75.000.000 RST
- Likuiditas masa depan: 10% = 50.000.000 RST
TOTAL: 100% = 500.000.000 RST

PENTING:
Angka-angka tersebut merupakan rencana alokasi, bukan bukti distribusi on-chain.
Kontrak Sepolia yang ada saat ini mencetak seluruh suplai awal kepada wallet deployer.
Pelaksanaan alokasi memerlukan transaksi transfer atau mekanisme kontrak yang sesuai.
Sepolia adalah testnet; tokennya tidak memiliki nilai uang nyata.
