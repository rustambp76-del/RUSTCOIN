RUSTCOIN WEBSITE — WALLET CONNECT + KIRIM RST
============================================
Fitur:
- Tombol Hubungkan Wallet untuk meminta koneksi MetaMask.
- Menampilkan alamat akun secara ringkas dan memeriksa jaringan Sepolia (Chain ID 11155111).
- Tombol Gunakan Sepolia untuk meminta wallet berpindah jaringan.
- Membaca saldo RST dari kontrak token dan tombol Perbarui Saldo.
- Form Kirim RST: alamat penerima dan jumlah token.
- Mengirim transaksi ERC-20 transfer melalui MetaMask; pengguna harus memeriksa dan menyetujui sendiri.
- Menampilkan tautan transaksi Sepolia Etherscan dan mencoba mendeteksi konfirmasi.
- Tidak meminta seed phrase atau private key.

Konfigurasi:
- Token: RUSTCOIN (RST)
- Jaringan: Sepolia Testnet
- Chain ID: 11155111
- Kontrak: 0x3343f3De4dbCBB361823c7E571EAc2FF78C14109
- Fungsi transfer ERC-20: transfer(address,uint256)
- Desimal token: 18

Cara memasang:
1. Ekstrak ZIP.
2. Buka repositori https://github.com/rustambp76-del/RUSTCOIN
3. Klik Add file > Upload files.
4. Unggah semua file di paket ke folder utama/root, menggantikan index.html yang lama.
5. Klik Commit changes.
6. Tunggu GitHub Pages memperbarui, lalu buka situs dan tekan Ctrl+F5.
7. Hubungkan wallet dan pastikan jaringan Sepolia.
8. Untuk mengirim, masukkan alamat penerima dan jumlah RST, klik Kirim RST via MetaMask, lalu periksa semua detail di MetaMask sebelum menyetujui.

PENTING:
- Jangan pernah memasukkan Secret Recovery Phrase atau private key ke website.
- Pastikan alamat penerima, jumlah, kontrak, dan jaringan sebelum menyetujui transaksi.
- Pengirim memerlukan saldo RST yang cukup dan SepoliaETH untuk gas. SepoliaETH dan RST testnet bukan uang nyata.
- Jangan menyetujui transaksi yang detailnya tidak sesuai.
- Website mengirim transaksi hanya setelah pengguna mengklik tombol dan menyetujuinya di MetaMask.
