Cara memasang:
1. Ekstrak ZIP.
2. Buka repositori https://github.com/rustambp76-del/RUSTCOIN
3. Klik Add file > Upload files.
4. Unggah semua file di paket ke folder utama/root.
5. Klik Commit changes.
6. Tunggu GitHub Pages memperbarui, lalu buka situs dan tekan Ctrl+F5.
7. Klik Hubungkan Wallet, pilih akun di MetaMask, dan setujui koneksi.
8. Jika jaringan bukan Sepolia, klik Gunakan Sepolia dan setujui pergantian jaringan di MetaMask.

PENTING:
- Jangan pernah memasukkan Secret Recovery Phrase atau private key ke website.
- Hubungkan Wallet hanya meminta izin melihat alamat; setiap transaksi token tetap harus dikonfirmasi terpisah di wallet.
- Token RST di Sepolia adalah token uji, tidak memiliki nilai uang nyata.
