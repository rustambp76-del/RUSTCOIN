RUSTCOIN WEBSITE — TOKENOMICS UPDATE
=====================================
Paket ini memperbarui website RUSTCOIN dengan bagian Tokenomics.

Unggah file berikut ke direktori utama repositori GitHub:
- index.html
- RUSTCOIN_LOGO.png
- favicon.png
- favicon.ico

Di GitHub:
1. Buka repositori RUSTCOIN.
2. Klik Add file > Upload files.
3. Unggah semua file dari paket ini ke folder utama (root).
4. Klik Commit changes.
5. Tunggu GitHub Pages memperbarui website, lalu tekan Ctrl+F5.
