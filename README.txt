RUSTCOIN WEBSITE — ROADMAP UPDATE
==================================
Paket ini memperbarui bagian Roadmap website RUSTCOIN menjadi lima tahap.

File di dalam paket:
- index.html
- RUSTCOIN_LOGO.png
- favicon.png
- favicon.ico
- README.txt

Cara memasang:
1. Ekstrak ZIP.
2. Buka repositori GitHub RUSTCOIN:
   https://github.com/rustambp76-del/RUSTCOIN
3. Klik Add file > Upload files.
4. Unggah semua file ke folder utama (root) repositori.
5. Klik Commit changes.
6. Setelah GitHub Pages selesai memperbarui, buka website dan tekan Ctrl+F5.
